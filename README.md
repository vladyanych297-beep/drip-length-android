# Капельная лента — ESI.Company

Android-приложение для расчёта максимальной длины капельной ленты по внутреннему диаметру, шагу и выливу капельниц, давлению в начале и минимальному давлению в конце, перепаду высот.

## Установка

Скачайте APK из [последнего релиза](https://github.com/vladyanych297-beep/drip-length-android/releases/latest). Требуется Android 8.0 или новее.

## Обновления

При открытии приложение проверяет новые версии, скачивает APK и проверяет SHA-256, размер и подпись. Установку подтверждает Android. Расчёты работают без интернета, проверку обновлений можно отключить.

Постоянный адрес метаданных: https://github.com/vladyanych297-beep/drip-length-android/releases/latest/download/update.json
